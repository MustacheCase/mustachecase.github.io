zanadir and OpenSSF Scorecard

Both are open-source tools for repository and CI/CD security, and they answer different questions. Scorecard rates a project's security practices. zanadir reads the CI pipeline and grades whether the security checks it runs can actually fail the build. Most projects benefit from both.

When to use which

  • Use Scorecard to judge a project, or a dependency you are about to adopt, on its overall security hygiene.
  • Use zanadir to find out whether your own pipeline would stop a vulnerable dependency, a leaked secret or an injectable workflow, and to get the configuration that closes the gap.
  • Use both: zanadir counts a Scorecard workflow as one of the workflow security controls it looks for.
